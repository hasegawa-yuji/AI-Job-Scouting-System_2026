# 🚀 AI求人精査システム (AI Job Scouting System)

OpenAI API（gpt-4o-mini）を活用し、大量の求人Excelデータから「自分の職歴・希望条件」にマッチする案件を全自動で精査・スコアリングする実務特化型のPythonスクリプトです。

Power Automate for desktop (PAD) 等のRPAツールと組み合わせることで、転職サイトからの求人自動抽出からAI査定、Excelレポート出力までの一連のワークフローを完全自動化することを想定して設計しています。

---

## 🌟 主な機能と実務向けの工夫

### 1. 独自ロジックによる「ノイズ削減 ＆ フォールバック機能」
求人票の膨大なテキストから、判定に必要な重要キーワード（年収、休日、業務内容、必須条件など）が含まれる行だけを事前に抽出してAIに送信します。
- **メリット**: トークン代（API費用）の大幅な節約と、AIの誤判定リスクの低下。
- **セーフティ設計**: 抽出したテキストが少なすぎる（500文字未満、または5行未満）場合は、自動的に全文解析モードへ切り替わる頑丈なフォールバックロジックを搭載。

### 2. 実務運用に耐える安定化処理
- **Rate Limit（429エラー）対策**: 大量案件の解析時にAPI制限で止まらないよう、1リクエストごとに自動で1秒の待機時間（`time.sleep`）を挿入。
- **タイムアウト設定**: APIの応答遅延によるプログラムのフリーズを防ぐため、60秒のタイムアウトを設定。
- **データ厳格化**: `response_format={"type": "json_object"}` を採用し、AIの余計な挨拶を排除して100%純粋なJSONデータのみを出力。
- **エラーログの強化**: JSON解析失敗時やAPIエラー発生時、プログラムを停止させずに「AIの生出力テキスト」や「エラー詳細」をログに残して次の求人へスキップする例外処理を実装。

### 3. レポート自動装飾（openpyxl）
- 解析結果は「総合点」の高い順に自動ソートしてExcelへ出力。
- 条件付き書式（パステルカラー）を用い、高評価（緑）、低評価（赤）を自動色付け。
- 「即応募」判定の案件がある場合は、点数に関わらず最優先で一行丸ごと「黄色」でハイライトする実用的な装飾処理を実装。

## 🛠️ 評価軸（プロンプト設計）

単なる一般論での評価ではなく、転職市場に基づいた現実的かつ厳格な査定を行います。

- **高評価ターゲット**: 社内SE、情シス、IT運用管理、製造業・物流系のIT担当、DX推進補助、IT資産管理など（現場改善文化のある中小〜中堅企業）。
- **減点・警戒条件**: 高度な開発・上流専任、PL/PM必須条件、激務・マルチタスクが想起される危険ワード（「少数精鋭」「0→1」「自走」「スピード感」等）、および他県への数ヶ月単位の長期研修リスクの自動検知。
